
Назва проєкту
«STEMSpace»

## Опис проєкту
«STEMSpace» — це сайт вигаданого шкільного STEM-фестивалю. Він допомагає відвідувачам ознайомитися з програмою заходів, дізнатися про напрями фестивалю та створити власний маршрут.

Інформація про фестиваль
- Дата: 12 грудня 2026 року.
- Час: 10:00–13:00.
- Місце проведення: ліцей «Обрій».
- Учасники: учні 7–11 класів.

Усі дані про фестиваль, його назву, місце проведення та програму є вигаданими.

Структура сайту
- index.html — головна сторінка.
- program.html — програма фестивалю та фільтри подій.
- visitors.html — інформація для відвідувачів і відповіді на запитання.
- route.html — сторінка власного маршруту.
- style.css — оформлення сторінок.
- script.js — робота кнопок, фільтрів і маршруту.

Використані технології
- HTML — створення структури сторінок.
- CSS — оформлення та адаптація сайту для різних пристроїв.
- JavaScript — реалізація функцій сайту.
- LocalStorage — збереження власного маршруту після перезавантаження сторінки.

Використані матеріали
Тексти, назва, описи заходів, програма фестивалю та дизайн створені самостійно для цього проєкту.

Сторонні шаблони та готові сайти не використовувалися. Зовнішні зображення та матеріали не використовувалися.

Умови використання
Сайт створений з навчальною метою в межах конкурсного проєкту. Усі матеріали та дані фестивалю є вигаданими й використовуються лише для демонстрації роботи сайту.

Як відкрити сайт
Для перегляду потрібно відкрити файл index.html у браузері. Для коректної роботи всіх функцій рекомендується запускати сайт через локальний сервер.
